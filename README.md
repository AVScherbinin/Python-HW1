# Homework 01

Учебный проект на Python.

## Структура проекта

```text
homework-01/
├── src/
│   └── homework/
│       ├── __init__.py
│       └── main.py
├── tests/
│   └── test_main.py
├── README.md
├── requirements.txt
├── pyproject.toml
└── .gitignore
```

## Что делает программа

Программа:

1. Создаёт значения основных встроенных типов Python:

   * `int`
   * `float`
   * `bool`
   * `str`
   * `list`
   * `tuple`
   * `set`
   * `dict`
2. Формирует текстовый отчёт со значениями и их фактическими типами.
3. Добавляет в отчёт ФИО.
4. Вычисляет MD5 и SHA-256 для UTF-8 представления итогового отчёта.
5. Выводит отчёт и хеши в консоль.
6. Запрашивает адрес получателя.
7. Отправляет письмо с ФИО, MD5 и SHA-256 через SMTP Яндекс 360.
8. Пароль приложения запрашивается при запуске и не хранится в исходном коде.

## Запуск

Активировать виртуальное окружение:

```bash
source .venv/bin/activate
```

Запустить тесты:

```bash
pytest
```

Запустить программу:

```bash
python -m homework.main
```

При запуске программа запрашивает адрес получателя и пароль приложения.

## Отправка электронной почты

Для отправки используется корпоративная почта НИУ ВШЭ на базе Яндекс 360.

SMTP-сервер:

```text
smtp.yandex.ru
```

Порт:

```text
465
```

Используется SSL-соединение.

Пароль от почтового аккаунта не хранится в проекте. Для SMTP используется отдельный пароль приложения, который вводится пользователем при запуске программы.

### Основные prompts

В процессе разработки использовались запросы следующего типа:

* Создать структуру Python-проекта с `src`, `tests`, `pyproject.toml` и виртуальным окружением.
* Создать программу, которая формирует значения типов `int`, `float`, `bool`, `str`, `list`, `tuple`, `set`, `dict` и выводит их значения и типы.
* Сформировать единый текстовый отчёт и добавить в него ФИО.
* Вычислить MD5 и SHA-256 от UTF-8 представления отчёта.
* Вынести вычисление хешей в отдельную функцию и написать pytest-тест с известной строкой.
* Реализовать отправку итогового отчёта по электронной почте без хранения пароля в исходном коде.
* Настроить отправку через корпоративную почту `@edu.hse.ru` на базе Яндекс 360.
* Исправить ошибки в коде и подготовить программу к финальному запуску.

### Обнаруженные ошибки и неточности

В процессе работы были обнаружены и исправлены ошибки и неудачные решения.

1. В одном из первоначальных вариантов был указан неверный контрольный результат SHA-256 для тестовой строки. Это было обнаружено при независимой проверке с помощью команды:

```bash
printf "Hello, world!" | sha256sum
```

После проверки ожидаемое значение в тесте было исправлено.

2. В процессе редактирования `main.py` возникла ошибка отступов `IndentationError`. Она была исправлена после запуска программы и анализа сообщения интерпретатора Python.

3. В первоначальной реализации отправка письма выполнялась непосредственно при импорте модуля. Это было нежелательно, поскольку тест, импортирующий функцию `calculate_hashes`, мог одновременно попытаться отправить письмо. Исполнение программы было вынесено в функцию `main()` и защищено конструкцией:

```python
if __name__ == "__main__":
    main()
```

Таким образом, функции проекта можно безопасно импортировать в тестах без запуска отправки электронной почты.

Все существенные результаты, полученные с помощью LLM, проверялись фактическим запуском программы, тестами или независимыми инструментами.
